# NovaPOS Print Agent

Descargas oficiales del agente de impresión para **Windows de 64 bits**. El agente recibe los trabajos de tu sucursal y los envía a las impresoras configuradas en NovaPOS.

**Normal** usa la presentación habitual de las comandas. **XXL** muestra texto más grande en las comandas de preparación. Elige la variante que ya usas al actualizar.

La versión estable también está en **Configuración → Impresoras y dispositivos** dentro de [NovaPOS](https://www.novapos.co).

## Actualizar en Windows

1. En la bandeja de Windows, abre el menú del agente anterior y selecciona **Salir**.
2. Descarga y abre el ejecutable nuevo con el mismo usuario de Windows.
3. Comprueba que el agente muestra tu negocio y tus impresoras. La sesión guardada se recupera si sigue vigente. Si caducó o fue revocada, inicia sesión una vez.
4. Envía una impresión de prueba y verifica que salga por su impresora.

En un equipo de pruebas, comprueba Cocina, Barra y precuenta. Si usas el inicio automático, reinicia Windows para verificar también la reconexión.
